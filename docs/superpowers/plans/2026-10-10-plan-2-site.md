# Kế hoạch 2: Markdown, design tokens & site đọc Astro — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng `packages/markdown` (Markdown → HTML an toàn, tô màu code), `packages/ui-tokens` (màu/font C1) và `apps/site` (Astro 7, SSG song ngữ `vi`/`ja`) — `pnpm --filter @blog/site build` sinh site hoàn chỉnh từ dữ liệu mẫu, kèm chỉ mục tìm kiếm Pagefind.

**Architecture:** Site **không đọc DynamoDB**: nó đọc hai file JSON `posts.json` và `tags.json` trong thư mục `BLOG_DATA_DIR` (mặc định `apps/site/fixtures`). Kế hoạch 3 (Lambda Build) sẽ query DynamoDB, ghi hai file này rồi chạy build. Logic chọn bản hiển thị, URL, nhóm theo năm nằm trong các module TypeScript thuần ở `apps/site/src/lib` (test bằng Vitest); file `.astro` chỉ trình bày. Markdown được chuyển HTML **lúc build** bằng `@blog/markdown` (unified + sanitize + Shiki dual theme); trang quản trị (Kế hoạch 5) dùng lại đúng package này cho xem trước.

**Tech Stack:** Astro 7.3.5 (Vite 8), unified 11 / remark / rehype, `@shikijs/rehype` 4.5.0, `rehype-sanitize` 6, Pagefind 1.5.2, Fontsource 5.3.0 (Be Vietnam Pro, Noto Sans JP, JetBrains Mono), zod 4.6.5, Vitest 5.0.3, TypeScript 7.0.2.

## Global Constraints

- Ràng buộc chung của Kế hoạch 1/1b vẫn áp dụng (pnpm catalog, TS strict, Biome, commit trailer, **không dùng `minimumReleaseAgeExclude`**).
- Phiên bản thư viện mới (thêm vào `catalog:`): `astro 7.3.5`, `pagefind 1.5.2`, `unified 11.0.5`, `remark-parse 11.0.0`, `remark-gfm 4.0.1`, `remark-rehype 11.1.2`, `rehype-sanitize 6.0.0`, `rehype-slug 6.0.0`, `rehype-stringify 10.0.1`, `@shikijs/rehype 4.5.0`, `unist-util-visit 5.1.0`, `@types/hast 3.0.5`, `@fontsource/be-vietnam-pro 5.3.0`, `@fontsource/noto-sans-jp 5.3.0`, `@fontsource/jetbrains-mono 5.3.0`.
- **Markdown:** HTML thô trong Markdown bị bỏ; đầu ra qua `rehype-sanitize` (schema mặc định) **trước** Shiki; ảnh `loading="lazy" decoding="async"`.
- **Shiki:** `themes: { light: "github-light", dark: "github-dark" }`, `defaultColor: "light"`; CSS đổi sang `--shiki-dark`/`--shiki-dark-bg` trong `@media (prefers-color-scheme: dark)`.
- **Astro:** `output: "static"`, `build.format: "directory"`, `trailingSlash: "always"`, `compressHTML: true` (giữ khoảng trắng giữa thẻ inline — mặc định Astro 7 là `"jsx"`), `prefetch: { prefetchAll: true, defaultStrategy: "hover" }`, `<ClientRouter />` từ `astro:transitions`.
- **Không gọi Google Fonts** — font tự host qua Fontsource (có subset `vietnamese` và chia `unicode-range` cho tiếng Nhật).
- **URL:** `/{vi,ja}/`, `/{vi,ja}/posts/<slug>/`, `/{vi,ja}/tags/`, `/{vi,ja}/tags/<key>/`, `/{vi,ja}/search/`, `/404.html`; `/` = trang chủ tiếng Việt + script chuyển sang `/ja/` khi `localStorage.lang === "ja"`.
- **Chọn bản hiển thị** (spec 2.2): bản ngôn ngữ giao diện nếu `published`, ngược lại bản kia; bài không có bản nào `published` không sinh trang. Chỉ bản `published` lọt vào site.
- **Ngày:** HTML chứa `<time datetime="<ISO UTC>" data-local-date>YYYY-MM-DD (UTC)</time>`; script đổi sang ngày theo múi giờ máy người đọc, định dạng `YYYY-MM-DD`, chạy lại sau mỗi lần chuyển trang (`astro:page-load`). Nhóm theo năm lúc build dùng năm UTC.
- **Ảnh bìa:** spec 2.5 nói lấy `width`/`height` lúc build; kế hoạch này **không đọc file ảnh** (ảnh nằm trên S3). Thay vào đó khung ảnh có `aspect-ratio: 16 / 9` + `object-fit: cover` để không nhảy bố cục. `coverImage` luôn đi qua thuộc tính Astro (tự escape).
- `astro check` **không dùng** (chưa chắc hỗ trợ TypeScript 7): `typecheck` của site chỉ chạy `tsc` trên `src/lib`, `src/i18n` và test; lỗi trong file `.astro` lộ ra ở bước build (build test).
- Build test chạy `astro build && pagefind` thật trên dữ liệu mẫu — timeout Vitest 180 s.

1. **Bài nháp / bản nháp lọt ra site**: bài chỉ có bản nháp không sinh trang; bản `ja` còn nháp của bài đã đăng `vi` không có URL, không hiện nút chuyển bản dịch. → Task 3 (unit), Task 6 (build).
2. **Nội dung độc hại trong Markdown**: `<script>`, `<img onerror>`, link `javascript:` bị loại; code block ngôn ngữ lạ không làm build lỗi. → Task 1.

```ts
import type { Root } from "hast";
import { visit } from "unist-util-visit";

/** Adds loading="lazy" and decoding="async" to every <img>. */
export function lazyImages() {
  return (tree: Root) => {
    visit(tree, "element", (node) => {
      if (node.tagName === "img") {
        node.properties.loading = "lazy";
        node.properties.decoding = "async";
      }
    });
  };
}
```

`packages/markdown/src/readingTime.ts`:
```ts
import type { Lang } from "@blog/shared";

const WORDS_PER_MINUTE = 200;
const JA_CHARS_PER_MINUTE = 500;

export function readingMinutes(markdown: string, lang: Lang): number {
  const text = markdown.replace(/```[\s\S]*?```/g, " ");
  const minutes =
    lang === "ja"
      ? text.replace(/\s/g, "").length / JA_CHARS_PER_MINUTE
      : text.split(/\s+/).filter(Boolean).length / WORDS_PER_MINUTE;
  return Math.max(1, Math.round(minutes));
}
```

`packages/markdown/src/index.ts`:
```ts
import rehypeShiki from "@shikijs/rehype";
import rehypeSanitize from "rehype-sanitize";
import rehypeSlug from "rehype-slug";
import rehypeStringify from "rehype-stringify";
import remarkGfm from "remark-gfm";
import remarkParse from "remark-parse";
import remarkRehype from "remark-rehype";
import { unified } from "unified";
import { lazyImages } from "./lazyImages";

export { readingMinutes } from "./readingTime";

function createProcessor() {
  return (
    unified()
      .use(remarkParse)
      .use(remarkGfm)
      // allowDangerousHtml stays off: raw HTML in Markdown is dropped here.
      .use(remarkRehype)
      // Sanitize before highlighting so Shiki's inline styles are not stripped.
      .use(rehypeSanitize)
      .use(rehypeSlug)
      .use(lazyImages)
      .use(rehypeShiki, {
        themes: { light: "github-light", dark: "github-dark" },
        defaultColor: "light",
        fallbackLanguage: "text",
      })
      .use(rehypeStringify)
  );
}

let processor: ReturnType<typeof createProcessor> | undefined;

/** Markdown -> sanitized HTML. The processor (and its Shiki highlighter) is created once. */
export async function renderMarkdown(markdown: string): Promise<string> {
  processor ??= createProcessor();
  return String(await processor.process(markdown));
}
```

> Nếu `tsc` báo `fallbackLanguage` hoặc `defaultColor` không tồn tại trong kiểu tuỳ chọn của `@shikijs/rehype` 4.5.0, mở `node_modules/@shikijs/rehype/dist/*.d.mts`, tìm interface tuỳ chọn và dùng đúng tên trường tương ứng (ý nghĩa: ngôn ngữ dự phòng cho code block lạ; theme mặc định inline), ghi lại Ruling.

```ts
import { readFileSync } from "node:fs";
import { join, resolve } from "node:path";
import type { Post, Tag } from "@blog/shared";
import { z } from "zod";

const versionSchema = z.object({
  slug: z.string().min(1),
  title: z.string(),
  excerpt: z.string(),
  content: z.string(),
  status: z.enum(["draft", "scheduled", "published"]),
  publishAt: z.string().nullable(),
  publishedAt: z.string().nullable(),
  updatedAt: z.string(),
});

const postSchema = z.object({
  id: z.string().min(1),
  tags: z.array(z.string()),
  coverImage: z.string().nullable(),
  createdAt: z.string(),
  updatedAt: z.string(),
  version: z.number(),
  versions: z.object({ vi: versionSchema.optional(), ja: versionSchema.optional() }),
});

const tagSchema = z.object({
  key: z.string().min(1),
  names: z.object({ vi: z.string().optional(), ja: z.string().optional() }),
});

export interface SiteData {
  posts: Post[];
  tags: Tag[];
}

export function dataDir(env: Record<string, string | undefined> = process.env): string {
  return env.BLOG_DATA_DIR ?? resolve(process.cwd(), "fixtures");
}

function readJson<T>(dir: string, file: string, schema: z.ZodType<T>): T {
  try {
    return schema.parse(JSON.parse(readFileSync(join(dir, file), "utf8")));
  } catch (err) {
    const reason = err instanceof Error ? err.message : String(err);
    throw new Error(`invalid site data in ${join(dir, file)}: ${reason}`);
  }
}

export function loadSiteData(dir: string = dataDir()): SiteData {
  return {
    posts: readJson(dir, "posts.json", z.array(postSchema)),
    tags: readJson(dir, "tags.json", z.array(tagSchema)),
  };
}

let cached: SiteData | undefined;

/** Loads the data once per build. */
export function siteData(): SiteData {
  cached ??= loadSiteData();
  return cached;
}
```

```ts
import { type Lang, type LangVersion, otherLang, type Post, type Tag } from "@blog/shared";
import { urls } from "./urls";

export interface PostPage {
  post: Post;
  /** Language of the page chrome. */
  ui: Lang;
  /** Language of the version shown (differs from `ui` when only the other one is published). */
  lang: Lang;
  version: LangVersion;
  url: string;
  /** The same post's page under the other UI language. */
  altUrl: string;
  /** The other published version, only when both are published. */
  translationUrl: string | null;
}

const published = (post: Post, lang: Lang): LangVersion | undefined => {
  const version = post.versions[lang];
  return version?.status === "published" ? version : undefined;
};

export function postPage(post: Post, ui: Lang): PostPage | null {
  const alt = otherLang(ui);
  const own = published(post, ui);
  const other = published(post, alt);
  const version = own ?? other;
  if (!version) return null;
  const altVersion = other ?? version;
  return {
    post,
    ui,
    lang: own ? ui : alt,
    version,
    url: urls.post(ui, version.slug),
    altUrl: urls.post(alt, altVersion.slug),
    translationUrl: own && other ? urls.post(alt, other.slug) : null,
  };
}

export function postPages(posts: Post[], ui: Lang): PostPage[] {
  return posts
    .flatMap((post) => {
      const page = postPage(post, ui);
      return page ? [page] : [];
    })
    .sort((a, b) => (b.version.publishedAt ?? "").localeCompare(a.version.publishedAt ?? ""));
}

export interface YearGroup {
  year: string;
  pages: PostPage[];
}

/** Expects pages sorted newest first; groups by the UTC year of publishedAt. */
export function byYear(pages: PostPage[]): YearGroup[] {
  const groups: YearGroup[] = [];
  for (const page of pages) {
    const year = (page.version.publishedAt ?? "").slice(0, 4);
    const last = groups.at(-1);
    if (last && last.year === year) last.pages.push(page);
    else groups.push({ year, pages: [page] });
  }
  return groups;
}

export function tagName(tags: Tag[], key: string, ui: Lang): string {
  return tags.find((tag) => tag.key === key)?.names[ui] ?? key;
}

export interface TagEntry {
  key: string;
  name: string;
  count: number;
  url: string;
}

export function tagEntries(pages: PostPage[], tags: Tag[], ui: Lang): TagEntry[] {
  const counts = new Map<string, number>();
  for (const page of pages) {
    for (const key of page.post.tags) counts.set(key, (counts.get(key) ?? 0) + 1);
  }
  return [...counts]
    .map(([key, count]) => ({ key, name: tagName(tags, key, ui), count, url: urls.tag(ui, key) }))
    .sort((a, b) => b.count - a.count || a.key.localeCompare(b.key));
}

export const pagesWithTag = (pages: PostPage[], key: string): PostPage[] =>
  pages.filter((page) => page.post.tags.includes(key));
```

`apps/site/src/pages/[lang]/search.astro`:
```astro
---
import { LANGS, type Lang } from "@blog/shared";
import { t } from "../../i18n";
import Base from "../../layouts/Base.astro";
import { urls } from "../../lib/urls";

export function getStaticPaths() {
  return LANGS.map((lang) => ({ params: { lang } }));
}

const ui = Astro.params.lang as Lang;
const dict = t(ui);
const other: Lang = ui === "vi" ? "ja" : "vi";
---

<Base ui={ui} title={`${dict["search.title"]} · ${dict.siteName}`} altUrl={urls.search(other)}>
  <link rel="stylesheet" href="/pagefind/pagefind-ui.css" />
  <h1 class="year">{dict["search.title"]}</h1>
  <div id="search"></div>
  <script is:inline src="/pagefind/pagefind-ui.js"></script>
  <script is:inline>
    new PagefindUI({ element: "#search", showSubResults: false, showImages: false });
  </script>
</Base>
```

> Link `search` trong header có `data-astro-reload` (Task 5) nên trang tìm kiếm luôn được tải đầy đủ — script của Pagefind chạy đúng một lần.
